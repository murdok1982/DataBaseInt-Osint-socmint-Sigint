# .antigravity — prompts de la herramienta Antigravity

Este directorio conserva los prompts y la auditoría SDD de la herramienta
Antigravity (`sdd-constitution.md`, `agent-*.prompt.md`, `audit/`).

La definición canónica de los agentes del equipo vive en `.opencode/agents/`,
según la configuración global del equipo. Si un prompt de aquí contradice a
`.opencode/agents/`, gana `.opencode/agents/`. Este directorio se mantiene por
compatibilidad; no añadas agentes nuevos aquí.
